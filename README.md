# NEO DENT

Сайт частной стоматологии в Санкт-Петербурге: услуги, врачи, цены, отзывы, запись и кабинет администратора. Данные лежат в `data/db.json`, отдельная база не нужна.

## Команды

```bash
npm install
npm run dev
```

Локально сайт открывается на порту 8080.

```bash
npm run typecheck
npm run build
npm start
```

`npm start` поднимает уже собранный сервер и слушает `PORT` (Railway подставляет его сам). Хост — `0.0.0.0`.

## Railway

1. Новый проект → Deploy from GitHub (или `railway up` из корня).
2. Сборка и старт уже прописаны в `railway.toml`. Ничего менять не нужно, если не хотите свой порт.
3. Переменные:
   - `ADMIN_PASSWORD` — от 12 символов. Без неё кабинет в проде не пускает никого.
   - `SESSION_SECRET` — длинная случайная строка. Если пусто, сессия считается от пароля.
   - `NEXTAUTH_URL` — публичный адрес сайта, `https://…up.railway.app`.
   - `DATA_FILE=/data/db.json` — если подключен том.
   - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — уведомление о записи. Если пусто, заявка всё равно сохраняется.
   - `VK_ACCESS_TOKEN` и `VK_PEER_IDS` — запасной канал, только если Telegram не ответил.
4. Том: Mount path `/data`. Без тома файл заявок живёт до перезапуска контейнера и потом создаётся заново из начальных данных.
5. После деплоя откройте сайт. Кабинет: `/admin`. Пароль с экрана входа не показывается.

Локальный просмотр (не production) принимает пароль `neodent-preview`. На Railway этот пароль не работает.
